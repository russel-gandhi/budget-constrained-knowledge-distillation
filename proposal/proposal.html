Budget-Constrained Knowledge Distillation:
Compressing Neural Networks via Sparse Optimisation

Project Proposal  ·  Team: SirCook  ·  Members: Russel Gandhi (BA2025041), Pratyush Prasad (BA2025034), Naman Sharma (BA2025025)

1. Problem Statement and Motivation

Modern neural networks achieve high accuracy but are too large for memory- and energy-limited devices (phones, microcontrollers). Knowledge distillation (KD) trains a small student network to mimic the softened output probabilities of a large, pre-trained teacher; these “soft targets” carry more information than hard labels. KD alone, however, does not control model size precisely. We pose compression as an explicit optimisation problem: train the student to match the teacher subject to a budget on the number of non-zero parameters, solve it with proximal gradient methods, and study the resulting accuracy-versus-size trade-off.

2. Mathematical Formulation

Variables: student weights $w \in \mathbb{R}^d$. Data: training pairs $(x_i, y_i)_{i=1}^N$, teacher logits $z^t(x_i)$ (fixed), student logits $z^s(x_i; w)$, temperature $T>0$, mixing weight $\alpha\in[0,1]$, $p^{(T)} = \mathrm{softmax}(z/T)$. Distillation objective:

$$F(w) = \frac{1}{N}\sum_{i=1}^{N}\Big[\alpha\,T^{2}\,\mathrm{KL}\big(p^{(T)}_{t}(x_i)\,\big\|\,p^{(T)}_{s}(x_i;w)\big) + (1-\alpha)\,\mathrm{CE}\big(y_i,\, p^{(1)}_{s}(x_i;w)\big)\Big]$$

Budget-constrained problem (the true goal; non-convex, combinatorial):   $\min_{w} F(w)\ \ \text{s.t.}\ \ \|w\|_0 \le k$, where $k$ is the parameter budget. We study three tractable formulations:

  1. $\ell_1$-regularised (convex relaxation of the budget): $\ \min_w F(w) + \lambda\|w\|_1$;  $\lambda$ is swept to reach different sizes.
  2. Hard budget via projection: $\ \min_w F(w) + \iota_{\{\|w\|_0\le k\}}(w)$, where $\iota$ is the indicator function; its proximal operator is projection onto the $k$-sparse set (keep the $k$ largest-magnitude entries).
  3. Structured (group) sparsity: $\ \min_w F(w) + \lambda\sum_{g\in\mathcal{G}}\|w_g\|_2$, where each group $g$ is all weights of one neuron/filter, so entire neurons are removed (real speed-ups, not only memory savings).

3. Planned Method and Solver

All three problems have the form smooth loss + non-smooth term, which is exactly the setting of proximal gradient descent. With step size $\eta$, each iteration is

$$w^{(j+1)} = \mathrm{prox}_{\eta h}\big(w^{(j)} - \eta\,\nabla \hat F(w^{(j)})\big),$$

where $\nabla\hat F$ is a mini-batch gradient (computed with PyTorch autograd) and the proximal operators are implemented from scratch:soft-thresholding $\mathrm{sign}(v)\max(|v|-\eta\lambda,0)$ for $\ell_1$ (ISTA), hard-thresholding for the $\ell_0$ budget (Iterative Hard Thresholding), and block soft-thresholding $v_g\max(1-\eta\lambda/\|v_g\|_2,0)$ for group sparsity. We will also implement the accelerated variant (FISTA, Nesterov momentum) and backtracking line search for $\eta$.

  • Convex sanity check: with a linear (softmax-regression) student, $F$ is convex, so we can compare ISTA vs. FISTA against the theoretical $O(1/j)$ vs. $O(1/j^2)$ rates and verify the optimum against cvxpy.
  • Main experiment: teacher = large pre-trained CNN; student = small CNN/MLP; datasets MNIST / Fashion-MNIST, then CIFAR-10 if time allows.
  • Baselines: (a) student trained on labels only, (b) dense KD student, (c) KD followed by one-shot magnitude pruning, versus our (d) KD + $\ell_1$-prox, (e) KD + IHT, (f) KD + group-lasso.

4. Planned Analysis

  • Accuracy-vs-size Pareto curves (test accuracy against non-zero parameters / model size in KB) for every method, by sweeping $\lambda$ and $k$.
  • Does distillation help under a budget? KD vs. label-only training at equal size; effect of $T$ and $\alpha$.
  • Optimisation behaviour: convergence of objective and sparsity, ISTA vs. FISTA, step-size sensitivity, and how sparsity is distributed across layers.
